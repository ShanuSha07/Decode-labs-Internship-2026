# Decode-labs-Internship-2026

##Project 1 - Data Cleaning & Preparation

## Objective

The objective of this project is to clean and prepare a raw dataset by identifying missing values, checking duplicate records, and validating data formats.

## Dataset Overview

The dataset contains order, customer, product, and transaction-related information. Data cleaning was performed to ensure accuracy and consistency before analysis.

## Tasks Performed

1. Missing Value Analysis

* Checked all columns for missing values.
* Identified missing values in the CouponCode column.
* Handled missing CouponCode entries appropriately.

2. Duplicate Check

* Checked for duplicate records.
* Verified that there were no duplicate Order IDs.

3. Data Format Validation

* Verified date columns for consistent formatting.
* Validated numeric columns for correct data types.
* Checked text fields for consistency.

## Tools Used

* Microsoft Excel
* Filters
* Sorting
* Conditional Formatting

## Results

* Missing values identified and handled.
* No duplicate records found.
* No duplicate Order IDs found.
* Date formats verified.
* Numeric columns validated.

## Outcome

The dataset was successfully cleaned and prepared for further analysis. The cleaned dataset was used as the input for Project 2 - Exploratory Data Analysis (EDA).
