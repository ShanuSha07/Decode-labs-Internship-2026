# Project 2 - Exploratory Data Analysis (EDA)

## Objective

To analyze the cleaned dataset and identify patterns, trends, and outliers using descriptive statistics and Pivot Tables.

## Dataset

The cleaned dataset from Project 1 was used for Exploratory Data Analysis.

## Analysis Performed

1. Summary Statistics

* Total Orders: 1200
* Average Order Value: 1053.97
* Maximum Order Value: 3456.40

2. Product Analysis

* Printer was the most frequently ordered product with 181 orders.

3. Payment Method Analysis

* Online payment was the most preferred payment method with 258 transactions.

4. Coupon Usage Analysis

* FREESHIP was the most used coupon code with 313 usages.

5. Outlier Detection

* The maximum order value (3456.40) was significantly higher than the average order value (1053.97), indicating potential high-value outliers.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Descriptive Statistics

## Outcome

Successfully performed Exploratory Data Analysis (EDA) and identified key business insights from the dataset.
