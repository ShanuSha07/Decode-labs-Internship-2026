# Project 3 - SQL Data Analysis

## Objective

The objective of this project is to use SQL queries to extract meaningful insights from a transactional dataset. SQL was used to perform filtering, sorting, grouping, and aggregation operations to support business analysis.

## Dataset

The cleaned dataset from previous projects was imported into MySQL and analyzed using SQL queries.

## SQL Concepts Used

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* COUNT()
* SUM()
* AVG()
* MAX()

## Analysis Performed

### 1. Total Orders

Calculated the total number of orders in the dataset.

### 2. Average Order Value

Calculated the average order amount using SQL aggregate functions.

### 3. Maximum Order Value

Identified the highest order value in the dataset.

### 4. Product Analysis

Analyzed product-wise order counts using GROUP BY.

### 5. Payment Method Analysis

Analyzed customer payment preferences.

### 6. Coupon Usage Analysis

Evaluated coupon code usage across transactions.

### 7. Revenue Analysis

Calculated total revenue generated by each product category.

### 8. Filtered Analysis

Used WHERE clauses to identify:

* Orders above average value
* Online payment transactions
* FREESHIP coupon transactions

## Key Insights

* Printer was the most ordered product.
* Online was the most preferred payment method.
* FREESHIP was the most frequently used coupon.
* Chair generated the highest revenue.
* High-value transactions were identified using filtering techniques.

## Outcome

Successfully performed SQL-based data analysis and generated business insights using filtering, grouping, sorting, and aggregation queries.
